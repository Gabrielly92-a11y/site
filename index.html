O que é Git

Git é um sistema de controle de versão distribuído, amplamente utulizado no desenvolvimento de software para rastrear mundaças no código-fonte durante o desenvolvimento

Com o Git, você pode:

  • Controlar versões do seu código
  • Trabalhar em equipe de forma organizada
  • Voltar para versões anteriores quando necessário
  • Experimentar novas ideias sem medo de perder o trabalho

Por que usar Git com VSCODE?

O VSCode possui integração nativa com Git, tornando o controle da versãomais visual e acessível para Iniciantes.

Configuração Inicial

Antes de começar, vocêprecisa configurar o Git no seu pc:

# Configurar seu nome de usuário
git config --global user.name "Seu nome"

# Configurar seu email
git config --global user.email "email@exemplo.com"

# Verificar configurações
git config --list

Inicializando um Repositório

Para começar a usar Git em um projeto, você precisa inicializar um repositório:

# Navegue até a pasta do seu projeto
cd caminho/para/seu/projeto

# Inicialize o repositório Git
git init

Comandos Básicos do Git

Estes são os comandos mais importantes que você usará regularmente:

git status

Mostra o estado atual do seu repositório: arqivos modificados, adicionados, etc.

git status

git add

Adiciona arquivos no staged ares, preprando-os para serem commitados.

# Adicionar um arquivo específico
git add arquivo.html

# Adicionar todos os arquivos
git add .

git commit

Salva as mundaças no repositório com uma mensagem descritiva.

git commit -m "Mensagem descritiva das mundaças"

git log

Mostra o histórico de commits do repositório.

git log

git branch

Lista, cria ou deleta branches (ramificações) no repositório.

# Listar branches
git branch

# Criar nova branch
git branch nova-feature

# Deletar branch
git branch -d branch-para-deletar

git checkout

Muda entre branches ou restaura arquivos.

# Mudar para uma branch
git checkout nome-da-branch

# Criar e mudar para nova branch
git checkout -b nova-branch

Fluxo de Trabalho Básico

Um fluxo de trabalho com o Git envolve estes passos:

  1. Modificar arquivos - Faça mudanças no seu código
  2. Verificar status - Use git status para ver o que mudou
  3. Adicionar mudanças - Use git add para preprar as mudanças
  4. Commit - Use git add para salvar as mudanças
  5. Repetir - Continue este ciclo conforme desenvolve

Exemplo Prático

# 1.Verificar status
git status

# 2.Adicionar todos os arquivos modificados
git add .

# 3.Fazer commit com mensagem
git commit -m "Adiciona funcionalidade X"

# 4.Verificar histórico
git log --oneline
